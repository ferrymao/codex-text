# 开始背法语单词

网站已经发布好了。直接打开：

[打开法语背单词网站](https://ferrymao.github.io/codex-text/)

不需要安装开发软件，不需要输入命令，也不用设置 GitHub。

## 第一次使用

1. 打开网址，点左侧“每日复习”。
2. 点“开始今天的复习”，先想一想这个词的意思。
3. 点“揭晓答案”，再按自己的记忆情况选择一个按钮。

第一次打开时保持联网，等右上角显示“离线可用”。以后断网也可以继续学。

把网址收藏到浏览器，下次直接打开就行。学习进度会保存在你正在使用的浏览器里。

要听发音，点单词旁边的“朗读”。如果没有声音，点页面上的语音提示查看安装方法。
