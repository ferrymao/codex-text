# 法语背单词网站

这是已经做好的网页文件，不需要在电脑上安装开发软件，也不需要输入命令。

网站发布完成后，打开：https://ferrymao.github.io/codex-text/

## 开始学习

1. 点“每日复习”，再点“开始今天的复习”。
2. 先回想意思，再点“揭晓答案”。
3. 按自己的记忆情况选择四个按钮中的一个。

第一次打开时保持联网，等右上角出现“离线可用”，以后断网也能继续学习。学习记录保存在自己的浏览器里。朗读没声音时，点页面上的提示查看语音安装说明。

## 首次开通网址

如果网址还显示 404，进入 https://github.com/ferrymao/codex-text/settings/pages ，在 Source 选择“Deploy from a branch”，Branch 选择“gh-pages”，旁边选择“/(root)”，点 Save。保存后等几分钟再打开网站。这里只需要设置一次。

语料来源和许可见 SOURCES.md、source-records.json 与 LICENSES.md。
